SCHOLAXIA STUDENT — INSTALL ON WINDOWS
======================================

You received the Scholaxia Student app for Windows PC or tablet.

WHICH FILE TO USE
-----------------
Try in this order:

  1. Scholaxia-Student-Portable-1.0.4.exe  (no install — try this FIRST if Setup failed)
  2. Scholaxia-Student-Setup-1.0.4.exe     (installer)

IMPORTANT: Download the full file (~45 MB). If sent via WhatsApp, the file may be
corrupted — ask for a Google Drive / WeTransfer link instead.

Do NOT use:
- Files inside the "win-unpacked" folder (developer build only)
- START.bat / BUILD-INSTALLER.bat (developers only)

WHAT YOU NEED
-------------
- Windows 10 or Windows 11 (64-bit)
- Internet connection
- About 300 MB free disk space

IF YOU SEE "This file does not have an app associated with it"
--------------------------------------------------------------
This usually means Windows shortcuts (.lnk) are broken on that PC. Try these:

  A) PORTABLE (easiest)
     Double-click Scholaxia-Student-Portable-1.0.1.exe
     SmartScreen: More info → Run anyway

  B) DESKTOP BAT FILE (after Setup install)
     On Desktop, double-click "Scholaxia Student.bat" (NOT the shortcut icon)
     Or: Start menu → Scholaxia Student → Scholaxia Student.bat

  C) RUN THE EXE DIRECTLY
     Open File Explorer and go to:
       %LOCALAPPDATA%\Programs\Scholaxia Student\
     Double-click ScholaxiaStudent.exe

  D) FIX WINDOWS SHORTCUTS (if nothing above works)
     Search Google for: "repair lnk file association windows 10"
     Then try the Desktop shortcut again.

If you see "This app can't run on your PC":
- Your PC may be 32-bit Windows — Scholaxia needs 64-bit (Settings → System → About)
- Re-download the full installer — file may be incomplete
- Click "More info" → "Run anyway" if Windows SmartScreen blocks it

INSTALL STEPS (Setup file)
--------------------------
1. Close Scholaxia if already open
2. Double-click Scholaxia-Student-Setup-1.0.1.exe
3. If SmartScreen appears: More info → Run anyway
4. Follow the wizard → Finish
5. Open "Scholaxia Student.bat" from Desktop (recommended)
   or Scholaxia Student from Start menu

PORTABLE (no install)
---------------------
1. Double-click Scholaxia-Student-Portable-1.0.1.exe
2. Allow if Windows asks — same SmartScreen steps as above

Teachers: use TEACHER.bat on the teacher's computer (not the student installer).

Support: contact the person who sent you this app.
